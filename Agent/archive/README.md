# Agent 历史归档策略

这里用于存放不再属于当前工作范围、但仍需保留的状态快照或专题记录。

归档规则：

- 归档不等于通过；“范围关闭”“未通过”“历史参考”必须写清楚。
- 归档文件不再作为当前执行队列或当前验收清单的来源。
- 当前状态只写入 `../CURRENT_STATUS.md`、`../EXECUTION_FLOW.md` 和由脚本生成的 `../STATE.json`。
- 大规模迁移历史文件时，优先保留 Git 历史和原始 evidence 路径，避免丢失安全审计上下文。
- 归档文件名使用日期和主题，例如 `2026-09-p0-p6-closeout.md`。
