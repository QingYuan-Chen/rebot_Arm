# 示教录制、检查与回放

> 状态：IMPLEMENTED；类型：示教功能说明；适用范围：`rebotarm_teach` 与 `rebotarm_motion`；回放通过不等于真机安全。

## 功能概述

系统将重力补偿录制的原始 JSONL 作为输入，经过准备、重采样、重定时、起点对齐和碰撞预检后，才允许 dry-run 或 execute。

## 当前实现

- `TeachRecorderNode` 录制和文件所有权；
- 原子反馈批次、样本年龄和批次时间戳校验；
- 示教文件列表、设置和状态 payload；
- 速度/加速度/jerk 检查与轨迹构造；
- MoveIt 起点对齐、碰撞预检和运行时跟踪门；
- 由 `rebotarm_simulation` 提供 MuJoCo 独立示教预演入口；`rebotarm_teach` 只提供记录读取和准备逻辑。

示教包内的文件读写、数据模型、质量检查和轨迹准备分别归
`teach_record_io.py`、`teach_models.py`、`teach_quality.py` 和 `teach_preparation.py`。
MoveIt 预检与 Action 生命周期由专用辅助模块处理，`TeachReplayWorkflow` 继续统一
dry-run token、对齐、执行和停止状态，Dashboard 不复制回放实现。

六轴回放重定时统一归 `rebotarm_motion.trajectory_time_parameterization`，输入为规范
`joint1..joint6`、共享数值点、限值和倍速；`retime_teach_samples` 仅做录制格式适配。
少关节记录保留读取、查看和通用质量分析，进入回放重定时时明确拒绝。
历史 `time_parameterization_method` 继续可读并保留请求值，实际方法按字段等级报告
`c0/c1/c2_waypoint_retime`；请求 `ruckig` 时同时说明当前未提供 waypoint 适配器。
旧局部维度差分重定时、反向注入回调和未实现 Ruckig 分支已删除。位置处理、源节点、
统一缩放及完整曲线的解析限值/碰撞复核继续沿用现有流程。 维护整改后使用现有 306 行原始记录完成
MuJoCo C1 对齐、完整碰撞检查、取消和再次回放；证据见 [P005 维护整改验收](p005_prepared_trajectory.md#维护整改验收2026-11-04)。

录制格式保留夹爪总开口、源时间和有效性供查看；回放只按关节名称提取完整六轴，
页面明确提示“夹爪不参与回放”。旧六轴记录与含第七轴的记录均不覆盖原始文件，
派生六轴格式为 `.prepared.v5.jsonl`，保存执行用 q/v 或 q/v/a，以及原输入等级、参考等级、
速度和加速度来源；q/v 的 a 为空。原始文件、旧 v3/v4 和已有 v5 均不覆盖，重复派生加序号。
旧六轴记录可读，v4 的 a 仅为派生约束，不认定为实测；本轮从原记录重新生成。
派生文件只包含示教段，不包含本次起点对齐；诊断加速度、jerk 留在检查报告，不回填节点。
MoveIt 对齐使用 `ompl_reference` 保留指定起点；最终对齐、示教段和保持段拼接后，
统一绑定后端保持起点、重定时并复核实际曲线极值。执行准备不再改节点或时间。
夹爪需提前独立设置并完成，起点对齐和全路径碰撞检查使用新鲜实际开度，全段固定。
dry-run 令牌仍绑定执行能力，重连后须重做。详见 [P005 接口](p005_prepared_trajectory.md#修订协同接口)。
自动对齐时长随当前反馈重新计算，不作为用户设置参与令牌等值比较；手动时长、速度与
步数仍须一致。execute 无论如何都重新规划、检查最终曲线和碰撞，不复用旧碰撞结论。

### 缺少加速度的记录与 C1 拼接

录制反馈通常只有位置和速度。平滑/低通改变位置后，录制速度不再是新路径的导数，不能
直接与 MoveIt 的 q/v/a 段拼接。位置处理前先验证维度、有限性、严格时间顺序和导数字段
一致性；q→C0、q/v→C1、完整 q/v/a→C2，后续处理不升级输入等级。
本次 q/v 保留滤波后的源位置节点和相对时间，用非均匀三点差分生成派生参考速度，首末 v
归零；执行点 a 始终为空。关闭平滑和低通时保留输入中间 v，仅随时间缩放调整。
示教专用 MoveIt 适配保留规划 q、时间与中间 v，明确取消 a 约束并重建三次曲线，首末 v
归零。报告转换说明并保存原规划数据供对照，不沿用原曲线检查结论。普通 MoveIt 执行不变。
对齐、软启动、保持和示教使用同一等级，一次 FJT 接纳、执行和整体结果；同时间节点仅在
q/v/a 状态一致时合并。方法为 `c1_waypoint_retime`，不称 C2 或 Ruckig 保路径适配器。

重采样继续用于质量分析和显示，不将折线细分点当作新的曲线控制节点。跳变质量按原有
固定采样频率从实际曲线上计算；节点间距不等于周期命令跳变。动态判定用解析段内极值，
原始差分噪声诊断单独保留，不将跨 C1 节点差分尖峰当作三次段内 jerk。
报告最高连续性与节点左右加速度及其差值：C1 允许加速度跳变，段内 jerk 合格不代表
全程有界 jerk，诊断 a 不作为新的端点约束。
滤波及三次重建可能改变节点间路径，因此不能宣称原始折线完全不变。完整拼接后必须
重新检查模型位置及动态极值，使用示教与模型限值的较小值，纳秒编码后再次核验。
碰撞预检包含全部节点、内部位置极值，并使相邻样本关节跨度不超过 0.02 rad。
默认覆盖预算为 10000 点，超预算拒绝、不抽稀；这仍是离散检查，不是连续碰撞证明。
预览只检查示教段；dry-run 和 execute 重新检查包含对齐与保持段的完整曲线。

页面分别显示“轨迹准备/拼接”和“碰撞检查”。构建、拼接或重定时失败时，碰撞标为
“未检查”；只有实际碰撞查询失败才显示未知，发现碰撞显示碰撞。最终曲线生成后展示
真实时长，包含对齐、保持及重定时，不再用原录制时长冒充执行时长。
正式准备服务不运行离线阶梯误差对照网格，全部限值和碰撞覆盖保留，2 秒期限不变。

使用现有仿真工具可定向验证同类记录（必须先启动隔离的 MuJoCo/MoveIt/Dashboard）：

```bash
ROS_DOMAIN_ID=74 python3 scripts/validate_p005_simulation.py --ros \
  --teach-record teleop_records/teach_record.jsonl \
  --dashboard http://127.0.0.1:18089 --output log/teach_c1_acceptance
```

工具先核对 MuJoCo 与唯一 FJT、拒绝真实控制器图，复制输入后通过现有网页 API 验证
起点对齐、完整碰撞预检、取消及再次完整回放。运行环境仍需隔离真实串口。
