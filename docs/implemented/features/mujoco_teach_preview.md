# MuJoCo 示教轨迹预演

> 状态：IMPLEMENTED；类型：纯仿真功能说明；适用范围：六轴示教轨迹预演；不构成真实机械臂回放授权。

## 功能概述

功能读取既有示教 JSONL，复用平滑、滤波、重采样和重定时流程，在独立 MuJoCo 实例中播放准备后的轨迹，并生成质量报告。

## 当前实现

- 原始示教文件只读；
- 六轴轨迹准备和重定时；
- 轨迹时长、跟踪误差、接触和瓶子位移统计；
- headless 与可选 Viewer 预演。

## 验证结果

已验证示教 JSONL 能被读取、准备并在独立 MuJoCo 实例中预演，报告能够区分轨迹质量和仿真接触结果。

## 边界与未完成

该功能只覆盖六轴轨迹预演。MuJoCo 接触不代替 MoveIt 碰撞预检；预演通过也不代表真机安全、回放通过或抓取成功。
